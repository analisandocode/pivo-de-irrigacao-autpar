Cadastrar novo pivô

Um pivô (ou uma estufa) é o nível do meio entre cliente e dispositivo — pode ter vários dispositivos dentro (câmera + telemetria, por exemplo). Cadastra o pivô primeiro, os dispositivos vão dentro dele.

Cadastrar novo dispositivo

Cada ESP32 ganha uma chave própria e única — o device_id vem desse cadastro, o firmware não precisa (nem consegue) se declarar com outro nome. Nome de convenção sugerido: cliente-local-NN (ex: estufa-tomate-01). Ver NOMEACAO.md na raiz do repo.

Pivôs e dispositivos cadastrados

A chave (api_key) vai no config.h do ESP32 daquele dispositivo. O botão "copiar pivo_ids" monta a lista pronta (com ";") pra colar direto no emails_permitidos.txt — dá acesso ao(s) pivô(s) inteiro(s) daquele cliente, todos os dispositivos dentro incluídos.
